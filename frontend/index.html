What happens when you press Compare

Five stages, one pipeline. The page only shows what the run actually reports.

  1. 01

    Read the GeM page

    Plain HTTP and selectors pull the title, brand, model, specs and price. No model is involved yet.

  2. 02

    Understand the product (LLM)

    The LLM turns the listing into a search identity: a canonical name, brand, model, key identifiers and search words.

  3. 03

    Search three lanes at once

    Flipkart, Amazon and other Indian shops run together. A web search finds the other shops; every page is fetched by code.

  4. 04

    Filter, then check each listing

    A cheap title filter keeps the strongest listings per shop. The LLM then judges each one against the reference product.

  5. 05

    Safety checks and one retry

    Code checks the currency, the price band and the confidence threshold. The first result appears at once; gaps are retried once.
